# GEOG 524 — Lecture 1 hands-on starter (v0.1)

## Contents
- `week01/data/example_observations.txt` — small, commented, comma-delimited text file.
- `week01/python/GEOG524_Lecture1_FirstSteps_Python.ipynb` — Colab/Jupyter-ready Python notebook.
- `week01/R/GEOG524_Lecture1_FirstSteps_R.R` — equivalent R script, suitable for RStudio or an R-enabled Jupyter environment.

## Suggested in-class flow
1. Have students download the text file to their computer.
2. Demonstrate one route into Colab: upload from computer OR mount Google Drive.
3. Demonstrate the same basic workflow in R (for example, RStudio).
4. Inspect the raw file before reading it; discuss delimiters, headers, comment lines, units and missing-value conventions.
5. Read the file, inspect the resulting data object, and create one simple plot.

## Notes
- The sample observations are synthetic teaching data, not actual station observations.
- The Python notebook includes Colab upload and Drive-mount alternatives plus local Jupyter instructions. Students should run only one file-location option.
- The R script assumes the file is in the working directory unless its path is edited.
- This is a short orientation demonstration; it is not intended to teach all of R/Python or notebook operation in one class.
